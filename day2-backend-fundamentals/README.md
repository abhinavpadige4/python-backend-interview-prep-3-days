# Day 2: Backend Fundamentals

## Learning Objectives
- Understand SQL and database concepts
- Learn ORM fundamentals (SQLAlchemy/Django ORM)
- Study REST API design principles
- Practice database normalization and querying
- Learn about API serialization and pagination

## Topics Covered
1. **SQL Fundamentals**: SELECT, INSERT, UPDATE, DELETE, JOINs
2. **Database Design**: Normalization, indexing, transactions
3. **ORM Concepts**: Object-relational mapping, model relationships
4. **REST API Design**: Resources, HTTP methods, status codes
5. **API Best Practices**: Versioning, authentication, pagination, filtering
6. **Serialization**: JSON/XML conversion, data validation

## Practice Problems
Solve these 5 problems today:

### Problem 1: SQL Queries Practice
**Description**: Write SQL queries for common backend scenarios including joins, aggregations, and subqueries.

### Problem 2: ORM Basics
**Description**: Create model definitions and relationships using SQLAlchemy or Django ORM syntax.

### Problem 3: REST API Design
**Description**: Design RESTful endpoints for a resource with proper HTTP methods and status codes.

### Problem 4: Database Normalization
**Description**: Identify normalization issues and redesign schemas to 3NF.

### Problem 5: API Pagination and Filtering
**Description**: Implement pagination, sorting, and filtering logic for API endpoints.

## Expected Time Allocation
- Problem 1: 20-25 minutes
- Problem 2: 25-30 minutes
- Problem 3: 20-25 minutes
- Problem 4: 25-30 minutes
- Problem 5: 20-25 minutes
- Review and practice: 25-35 minutes
