# Day 1: Core Python & Data Structures

## Learning Objectives
- Master Python fundamentals and syntax
- Understand core data structures (lists, dicts, sets, tuples)
- Practice algorithmic problem-solving techniques
- Learn time and space complexity analysis

## Topics Covered
1. **Python Basics**: Variables, data types, control flow, functions
2. **Data Structures**: Lists, dictionaries, sets, tuples
3. **String Manipulation**: Parsing, formatting, regex basics
4. **Algorithms**: Sorting, searching, two pointers, sliding window
5. **Advanced Python**: List comprehensions, generators, decorators, context managers

## Practice Problems
Solve these 5 problems today:

### Problem 1: Two Sum (Easy)
**Description**: Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

**Link**: https://leetcode.com/problems/two-sum/

### Problem 2: Add Two Numbers (Medium)
**Description**: You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

**Link**: https://leetcode.com/problems/add-two-numbers/

### Problem 3: Longest Substring Without Repeating Characters (Medium)
**Description**: Given a string `s`, find the length of the longest substring without repeating characters.

**Link**: https://leetcode.com/problems/longest-substring-without-repeating-characters/

### Problem 4: Valid Anagram (Easy)
**Description**: Given two strings `s` and `t`, return `true` if `t` is an anagram of `s`, and `false` otherwise.

**Link**: https://leetcode.com/problems/valid-anagram/

### Problem 5: Merge Intervals (Medium)
**Description**: Given an array of `intervals` where `intervals[i] = [starti, endi]`, merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

**Link**: https://leetcode.com/problems/merge-intervals/
